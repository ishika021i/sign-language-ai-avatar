# AI Sign Language Recognition & 3D Avatar

An AI-powered sign language recognition and 3D avatar system.

## Project Goal

The system aims to:

- Recognize sign language gestures using computer vision and machine learning.
- Convert recognized signs into text.
- Represent signs using a 3D animated avatar.
- Allow text input to be converted into sign language animations.

## Technology Stack

- Python
- OpenCV
- MediaPipe
- Machine Learning
- React
- Three.js
- FastAPI
- Blender
